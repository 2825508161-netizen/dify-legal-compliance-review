# Mac 本地 AI 合同审核聊天产品

本目录将 Open WebUI v0.11.3 与第二阶段 Dify 合同审核工作流连接。Open WebUI 核心源码未修改；集成由可信 Pipe 和独立本地网关完成。

当前本机版本已经可以打开、上传合同、选择审核要求、查看中文结果并下载 Word/PDF。为避免误导，尚未取得 Dify 测试应用 API 授权前，页面会明确显示“模拟联调”，不会把模拟结果冒充真实审核。

## 一键使用

1. 双击 `scripts/start.command` 启动（第一次启动可能需要约 1 至 3 分钟）。
2. 浏览器打开 `http://127.0.0.1:3000`。
3. 在模型选择器选择“AI 合同审核（Dify 测试版）”。
4. 上传 PDF、DOCX 或 TXT 合同，发送“开始审核”。
5. 在弹窗中选择审核要求，等待报告。
6. 点击结果中的 Word 或 PDF 下载链接。

双击 `scripts/stop.command` 停止。双击 `scripts/status.command` 查看状态。停止后不会删除聊天记录和已生成报告。

## 安全边界

- 所有端口只监听 `127.0.0.1`，不开放公网。
- `.env.local` 保存本地配置并被 Git 忽略。
- Dify Key 不写入代码、不进入 Git，也不会输出到日志。
- Open WebUI 官方品牌保持不变，符合 v0.11.3 许可证要求。
- Open WebUI 使用无登录的本机单用户模式，不应改为公网部署。

## 模式说明

- `DIFY_MODE=mock`：验证上传、交互、进度、报告展示和下载，不代表真实 Dify 调用。
- `DIFY_MODE=live`：需要已发布的 Dify 测试应用和对应 API Key，才能执行真实调用。
